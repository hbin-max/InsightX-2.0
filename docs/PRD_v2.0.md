# 产品需求文档 (PRD)：InsightX 2.0 (AI 商业决策参谋)

## 1. 产品定位与核心价值
InsightX 是专为 **AI/SaaS 赛道商业化产品经理、业务负责人及一级市场投资人** 打造的高信噪比商业情报聚合与结构化决策参谋。

它通过自动化采集多模态资讯（长音频/播客、官方更新日志、财报电话会、高质量技术社区），经过商业大模型（LLM）多维降维萃取，以极其高效的 **Tinder-style（划卡）+ Bento Grid（便当盒网格）** 形式呈现核心决策情报。

---

## 2. 三大核心情报支柱 (Core Pillars)

### 支柱 1：新模型发布与技术速递 (New Model Radar)
- **目标**：解决技术信息分散、PR 水分大的问题，提炼纯粹的“模型硬指标与商业影响”。
- **卡片特化组件**：Bento 2×2 参数矩阵：
  - **架构规格**（如 671B MoE / MLA 架构 / 活跃参数）
  - **上下文长度**（如 128K / 1M 原生支持）
  - **商用协议**（开源可商用 Apache 2.0 / MIT vs 闭源限制）
  - **跑分评测**（LMSYS Chatbot Arena / MMLU / 代码评测）

### 支柱 2：Token 经济学与定价雷达 (Token Economics & Pricing Radar)
- **目标**：紧盯全网大模型与垂直 SaaS 价格战、计费模式重构（Seat-based ➔ Hybrid ➔ Outcome-based）。
- **卡片特化组件**：**交互式 ROI 动态测算滑块**：
  - 用户拖动日均调用量滑块（10万 ~ 300万次/日）；
  - 系统实时动态推演切换方案后的月节省金额与成本降幅。

### 支柱 3：播客与财报长音频决策内参 (Executive Audio Decryption)
- **目标**：攻克 1~2 小时海外硬核播客（Latent Space、20VC、Dwarkesh）与财报电话会收听成本过高的问题。
- **卡片特化组件**：**30 秒原声试听胶囊与时间戳锚点**：
  - 提炼高管/创始人亲口披露的真实成本与踩坑数据；
  - 内嵌声波波形播放条，支持一键试听关键发言原声；
  - 严格溯源对齐，杜绝幻觉。

---

## 3. 通用商业 4+1 提取要素
无论属于哪个支柱，所有情报卡片均强制遵守以下 5 个维度的结构化提炼：
1. **📄 核心事实提炼 (Summary)**：剔除技术自嗨，忠实提炼核心要点。
2. **💰 商业变现与定价 (Monetization & Pricing)**：收费逻辑与单位经济学测算。
3. **🎯 落地场景与风险阻碍 (Use Case & Friction)**：具体 B 端切入点及合规/延迟风险。
4. **💡 商业战略行动建议 (Action)**：面向高管的本周可落地实操动作。
5. **🏷️ 风险/机遇标签**：`颠覆预警 (Warning)` / `增长机遇 (Opportunity)` / `模式观察 (Normal)`。

---

## 4. 三大核心交互视图
1. **情报流 (Feed)**：Tinder 堆叠卡片，左滑忽略、右滑收藏进智库，毫秒级响应。
2. **态势矩阵 (Matrix Radar)**：二维散点图（横轴：落地阻碍，纵轴：商业价值与 ROI），宏观透视行业格局。
3. **情报智库 (Vault)**：管理收藏的情报，支持按标签过滤筛选及一键导出 Markdown 研报。

---

## 5. 技术架构设计
- **前端**：单文件现代纯客户端（HTML5 + Tailwind CSS + Phosphor Icons + Vanilla JS），具备完整的离线演示数据集与实时接口代理能力。
- **后端**：Python FastAPI + Uvicorn 异步服务。
- **采集处理链路**：
  - 文本流：Jina Reader / Firecrawl 抓取正文 Markdown；
  - 音频流：`yt-dlp` 音频提取 + Whisper ASR 语音识别与时间戳对齐；
  - 提取引擎：通义千问 Qwen / Claude 3.5 结构化 Prompt 管道。
