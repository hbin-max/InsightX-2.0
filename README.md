## ✦ 核心定位与特色

行业信息过载，但 90% 是技术自嗨或 PR 通稿。**InsightX 2.0** 将非结构化的全网资讯、技术发布与深度播客访谈，转化为可以直接指导商业决策的结构化情报卡片。

```

├──────────────────┬──────────────────────┬──────────────────────────────┤

├──────────────────┼──────────────────────┼──────────────────────────────┤
│ 🏷️ Bento 2×2 参数格      │ 🎚️ 交互式 ROI 动态推演滑块    │ 🎙️ 声波原声试听胶囊 (30s)    │
│ 架构 / 上下文 / 跑分 / 协议 │ 日调用量 ➔ 月节省实时推演   │ 精确定位发言时间戳出处       │
└──────────────────┴──────────────────────┴──────────────────────────────┘
```

### 1. 三大特化功能组件
- **🔥 新模型发布 (New Model Radar)**：Bento 式提炼模型架构（MoE/Dense）、原生上下文长度、商用协议（MIT/Apache 2.0）与 LMSYS Arena 核心基准跑分。
- **💰 Token 经济学 (Token Pricing Radar)**：监控 API 价格暴跌与计费模式突变，内嵌**无极 ROI 动态推演滑块**，拖动调用量实时核算降本空间。
- **🎙️ 播客与财报长音频 (Audio Decryption)**：攻克 1~2 小时海外硬核播客与财报电话会收听门槛，内嵌**30 秒原声试听波形胶囊**，直达创始人亲口披露的真实成本内幕。

### 2. 经典三大视图
- **✦ 情报流 (Feed)**：Tinder 堆叠卡片，手势**左滑忽略**、**右滑收藏入库**。
- **☩ 决策矩阵 (Matrix Radar)**：按“落地阻碍”与“商业价值/ROI”构建二维散点雷达，透视行业格局。
- **⚲ 智库 (Vault)**：管理收藏归档的情报卡片，支持标签过滤与**一键导出 Markdown 研报**。

## ⚡ 快速体验 (Quick Start)

### 方式一：前端纯客户端即开即用（无需安装任何环境）
本项目前端采用纯单页高保真架构，无需复杂打包，内置丰富的离线高价值情报数据集：
1. 直接在电脑浏览器中双击打开 `frontend/index.html`；
2. 即可体验完整的卡片滑动、Bento 参数格、ROI 动态测算滑块与原声波形播放；
3. 点击右上角设置图标，可配置本地私有的大模型 API Key（仅存储于浏览器本地 `localStorage`）。

### 方式二：启动 Python FastAPI 后端服务
```bash
# 1. 进入后端目录
cd backend

# 2. 安装 Python 依赖
pip install -r requirements.txt

# 3. 复制环境变量并配置密钥
cp .env.example .env

# 4. 启动服务
uvicorn app.main:app --reload --port 8000
```
启动后访问 `http://localhost:8000/docs` 可查阅 OpenAPI / Swagger 接口文档。

## 🛡️ 安全与隐私规范 (Security & Privacy)

- **零密钥泄露**：全量源码中不包含任何硬编码 API Key；
- **本地自治**：前端仅在本地浏览器 `localStorage` 中记录用户偏好与配置的 API 密钥；
- **事实求真**：所有引用的 ROI 效能数据及定价均附带溯源校验机制，杜绝大模型盲目脑补。
